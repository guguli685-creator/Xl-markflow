# ✨ MarkFlow - 沉浸手帐与书签空间

**MarkFlow** 是一款兼具轻手帐视觉美感与高效书签管理的 Web 应用。项目采用纯原生 HTML/CSS/JavaScript 构建，无需繁琐的依赖安装，双击即可直接运行，同时支持全端响应式自适应。

---

## 🌟 核心特色

### 🔖 自由画布与书签管理

* **灵活布局切换**：支持网格视图 (Grid)、紧凑双列 (Compact) 以及大卡片流 (List) 多种布局自由切换。


* **大文件夹与嵌套展开**：支持分类卡片展示，点击文件夹快速展开子页面悬浮窗，高效管理海量网址。


* **单条网址精准管理**：支持直接编辑网址名称、链接及单独的**网站备注**。


* **网页快捷预览与防内嵌保护**：选中网址条目后按下空格键即可呼出网页内嵌预览弹窗；针对启用防内嵌保护 (X-Frame-Options) 的网站提供一键新标签页直达的安全引导。



### 🎨 沉浸手帐笔记空间

* **沉浸式富文本写作**：独立的笔记编辑页面，支持 H1~H4 标题、加粗、斜体、下划线、引言区块及有序/无序列表。


* **苹果风格悬浮贴纸 Dock**：底部悬浮的 Dock 栏，支持顺畅挑选 Emoji 表情或自定义图片贴纸。


* **全端贴纸高级交互**：
* 支持拖拽或直接点击快速贴到笔记中心。


* 支持纯透明 PNG 贴纸与本地图片导入。


* 选中贴纸后支持 **360° 自由旋转** 与 **自由拉伸缩放**。


* 长按贴纸可快捷删除。





### 🔍 全局综合检索与标签

* **实时沉浸检索**：点击顶栏搜索框即可进入全屏检索模式，支持对“书签”与“手帐笔记”进行实时关键字过滤。


* **云端同步标签库**：支持添加自定义检索标签并一键同步至仓库的 `tags.json` 文件中。



### ☁️ 云端同步与数据管理

* **GitHub 自动备份与恢复**：绑定个人 GitHub Token 即可将书签混合流 (`data.fow`) 与笔记数据 (`notes.bj`) 实时同步或从仓库一键恢复。


* **HTML 导入与导出**：无缝兼容标准浏览器书签 HTML 文件（含备注信息）的导入与导出。


* **全端完美适配**：针对移动端手势、顶栏图标布局及全屏搜索框进行了深度响应式优化。


* **现代极简圆角滚动条**：采用统一的半透明圆角胶囊滑块。

## 🚀 快速开始

无需配置复杂的 Node.js 或构建环境，三步即可开启：

1. **克隆/下载仓库**：
```bash
git clone https://github.com/guguli685-creator/Xl-markflow.git

```


2. **打开应用**：直接双击打开 `index.html` 即可开始使用。


3. **云端同步**：点击左侧或顶栏的云端图标 (`☁️`) 绑定个人 GitHub Token，即可享受多端云端备份与恢复。
