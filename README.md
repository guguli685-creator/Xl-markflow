# ✨ MarkFlow - 沉浸手帐与书签空间

**MarkFlow** 是一款兼具轻手帐视觉美感与高效书签管理的 Web 应用。项目采用纯原生 HTML/CSS/JavaScript 构建，无需繁琐的依赖安装，双击即可直接运行，同时支持全端响应式自适应（移动端/桌面端）。

---

## 🌟 核心特色

### 🔖 自由画布与书签管理
- **自由卡片拖拽**：在无限画布上自由摆放书签分类卡片，自带柔和倾角与手帐贴纸风格。
- **大文件夹与嵌套展开**：支持分类卡片展示，点击文件夹快速展开子页面悬浮窗，高效管理海量网址。
- **单条网址精准管理**：支持直接编辑网址名称、链接及单独的**网站备注**。
- **防止拖拽误触**：内置像素级位移判定，精准区分卡片拖拽与点击展开悬浮窗操作。

### 🎨 沉浸手帐笔记空间
- **沉浸式写作**：独立的笔记编辑页面，支持 Markdown 常见格式（H1~H4、加粗、斜体、引言、列表）。
- **苹果风格悬浮贴纸 Dock**：底部悬浮的 Dock 栏，单指/鼠标左右滑动顺畅挑选贴纸。
- **全端贴纸交互**：
  - 支持拖拽或**直接点击**快速贴到笔记中心。
  - 支持**纯透明 PNG** 贴纸与自定义本地图片导入。
  - 选中贴纸支持**360° 自由旋转**与**自由拉伸缩放**。

### ☁️ 云端同步与多端自适应
- **GitHub 自动备份**：绑定个人 GitHub Token 即可将数据与生成的书签备份文件实时同步至私有/公开仓库。
- **HTML 导入与导出**：无缝兼容标准浏览器书签 HTML 文件的导入与导出。
- **全端完美适配**：针对移动端手势、顶栏图标布局及全屏搜索框进行了深度响应式优化。
- **现代极简圆角滚动条**：摒弃复古原生滚动条，采用统一的半透明圆角胶囊滑块。
